# Visualization quality gate

Complete this gate after smoke tests and before any publication.

- [ ] Every widget has an explicit source, time filter, and meaningful title.
- [ ] Compared periods have equal duration and timezone; partial periods are visibly identified.
- [ ] Metrics are normalized for volume differences where appropriate, with the denominator shown.
- [ ] `prompt_tokens`, `completion_tokens`, and `total_tokens` are distinct fields and are never conflated.
- [ ] Titles, axes, units, legends, colors, labels, and sort order communicate the intended measure.
- [ ] The visualization type supports the claim; conclusions describe observation, association, or experiment accurately.
- [ ] Filters behave as intended and the selected default is documented.
- [ ] The browser is open on the final draft or published resource, and its ID and URL match the script result.
- [ ] Close query previews, duplicate drafts, and other auxiliary browser tabs before handoff.
