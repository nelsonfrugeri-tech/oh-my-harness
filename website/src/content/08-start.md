## Comece pelo seu ambiente

O README mantém as instruções de instalação de **Claude Code** e **Codex**, os requisitos de cada caminho e os limites operacionais. Use-o como referência de execução para evitar duplicar comandos que podem mudar.

Depois da instalação, inspecione as capabilities configuradas na máquina. Faça uma tarefa pequena, confira os testes e observe se a resposta distingue evidência de inferência. Amplie o uso a partir do que você verificou.

### Um sistema de trabalho aberto à inspeção

O OMH é um projeto open source sob licença Apache 2.0. Seu propósito é centralizar artefatos compartilhados e específicos de cada harness, preservando uma maneira consciente de investigar, construir e comunicar.

### Sobre este guia

Esta primeira edição é uma apresentação narrativa em português e um roteiro para gravação. As fontes apontam para uma revisão identificada do projeto; o README da branch principal pode evoluir depois. O modo de apresentação usa o mesmo conteúdo, sem criar um segundo documento para manter.
